# パペット変形 for YMM4
 
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](#)
[![.NET](https://img.shields.io/badge/.NET-10.0-purple.svg)](#)
[![Release](https://img.shields.io/github/v/release/routersys/YMM4-PuppetDeformation.svg)](https://github.com/routersys/YMM4-PuppetDeformation/releases)
 
---
 
YukkuriMovieMaker4（YMM4）上で動作する、**ピンを打って画像を自由に変形させるパペットワープ映像エフェクトプラグイン**です。
HLSL ピクセルシェーダーを Direct2D カスタムエフェクトとして実装しており、GPU 上でのリアルタイムレンダリングが可能です。
Moving Least Squares（MLS）アルゴリズムに基づく剛体変換により、ピンの移動に追従した滑らかで自然な変形を実現します。
各ピンの位置・移動量はキーフレームアニメーションに対応しており、揺れ・うねり・表情の変化など多彩な演出が可能です。

## 概要
 
本プラグインは YMM4 の「映像エフェクト」として動作します。画像上に**ピン**を複数配置し、各ピンを移動させることで画像全体をリアルタイムに変形します。
 
内部的には Direct2D カスタムピクセルシェーダーエフェクト（`D2D1CustomShaderEffectBase`）として実装されており、HLSL コンパイル済みシェーダー（`.cso`）をエフェクトチェーン上で動作させます。
 
各出力ピクセルに対して、現在位置から **Moving Least Squares（MLS）剛体マッピング** の逆変換により元のサンプリング座標を算出し、入力テクスチャから色をサンプリングして変形後の映像を構成します。ピンデータは 1×MaxPins の `R32G32B32A32_Float` ビットマップとして GPU に渡されます（各ピクセルの XY が基準座標、ZW が移動後座標）。
 
ピンが 1 本の場合は並進のみ（全体シフト）、2 本以上の場合は MLS 剛体変換が適用されます。また、剛性（`Stiffness`）パラメータにより変形の局所性を制御できます。

## インストール方法
 
1. [Releases](https://github.com/routersys/YMM4-PuppetDeformation/releases/latest) ページから最新のプラグインファイル（`.ymme`）をダウンロードしてください。
2. YMM4 が起動していないことを確認し、ダウンロードしたファイルを実行（ダブルクリック）してインストールします。
3. YMM4 を起動し、タイムライン上のアイテムに映像エフェクトを追加します。
4. 映像エフェクトの種類として **「パペット変形」** を選択してください。

## 主な機能
 
### 1. MLS剛体変換による変形
 
ピンの配置と移動量をもとに、**Moving Least Squares（MLS）剛体変換**を用いて画像全体を変形します。各出力ピクセルの位置を逆方向にマッピングし、元画像のどの座標に対応するかを算出することで、引き伸ばしや折りたたみのない滑らかな変形を実現します。
 
GPU 上の HLSL シェーダーでは、ピンデータを 1×256 の `R32G32B32A32_Float` テクスチャとして受け取り、各ピクセルについて重み付き最小二乗による剛体近似を計算します。
 
### 2. ピンの二種類のポイント
 
各ピンは **基準ポイント**（○、白丸）と **移動ポイント**（●、色付き丸）の 2 種類のコントロールポイントを持ちます。
 
- **基準ポイント（Anchor）**: ピンを打つ元の位置です。変形の起点となり、このポイントをドラッグすると画像上のピンの位置自体を動かせます。
- **移動ポイント（Move）**: 基準ポイントからのオフセット先です。このポイントをドラッグすると画像が変形します。移動量がゼロの場合、移動ポイントは表示されません。
ビューポート上では基準ポイントと移動ポイントが線で結ばれ、現在の変形の方向・量を視覚的に確認できます。移動ポイントは移動方向に向かって回転したアイコンとして表示されます。
 
### 3. アンカーピンによる固定
 
各ピンは**有効 / 無効**を切り替えられます（「有効」トグル）。ピンを無効にすると、そのピンは**固定アンカー**として機能します。移動ポイントを持たずに基準位置を固定することで、変形が特定の領域に留まるよう制約をかけられます。無効なピンはビューポートでも透明度を下げて表示されます。
 
### 4. ドロネー三角形分割によるメッシュ表示
 
ビューポートには、移動ポイントの現在位置を頂点とした**ドロネー三角形分割メッシュ**がオーバーレイ表示されます。これにより、どの頂点がどの辺で繋がっているかを直感的に把握でき、変形のおおまかな構造を確認しながら操作できます。
 
ドロネー三角形分割は Bowyer-Watson アルゴリズムで実装されており、三角形の外接円内に他の頂点が入らないという特性から、細長い三角形が生じにくい良質なメッシュが生成されます。
 
### 5. ピンリストエディター
 
エフェクトのプロパティパネルには専用の**ピンリストエディター**が表示されます。ここではすべてのピンが空間的な位置関係を反映したグリッドレイアウトで一覧表示されます。グリッドの行・列はピンの基準X・基準Y座標をクラスタリングして自動決定され、空間配置と UI 配置が直感的に対応します。
 
各セルには基準ポイント（中央の○）と移動ポイント（矢印方向に配置された●）が表示されます。セルを選択すると、そのピンのパラメータ（有効・基準X・基準Y・移動X・移動Y）がプロパティエリアに表示されます。
 
ピンリストエディター上部のボタン群からは以下の操作が行えます。
 
- **ピンを追加**: 基準位置 (0, 0) に新しいピンを追加します（最大 256 本まで）。
- **選択中のピンを削除（−）**: 現在選択しているピンを削除します。
- **リセット（↺）**: 全ピンの移動量（移動X・移動Y）をゼロにリセットします。確認ダイアログが表示されます。
### 6. 同期モードによる複数ピンの連動操作
 
複数のピンを同時に選択した状態でドラッグすると、**同期モード**に従って他のピンも連動して動きます。
 
**なし**: 選択されたピンのみ個別に移動します。
 
**距離減衰**: ドラッグ中のピン（ソース）の移動量を基準に、他の選択ピンも基準座標間の距離に比例した割合で減衰しながら移動します。ソースピンから遠いほど移動量が小さくなるため、自然な波及変形が表現できます。減衰は選択ピンの基準座標バウンディングボックスの最大対角距離を基準に計算されます。
 
**平行移動**: 選択されたすべてのピンが同じ量だけ同じ方向に移動します。群れを一括操作する際に有用です。
 
同期はビューポートのドラッグ操作だけでなく、プロパティパネルのスライダー・キーフレーム編集時にも適用されます。
 
### 7. キーフレームアニメーション
 
各ピンの**基準X・基準Y・移動X・移動Y**、およびエフェクト全体の**剛性**はすべてキーフレームアニメーションに対応しています。タイムライン上でキーフレームを設定することで、ピンが時間とともに移動するアニメーションを作成できます。
 
### 8. 出力矩形の自動拡張
 
本エフェクトは、MLS 変形後に元画像の各領域が描画される可能性のある範囲を CPU 側で事前計算し、出力矩形を必要最小限に拡張します。グリッドサンプリング（96×96）によって逆マッピングの到達範囲を推定し、元画像の範囲内に収まる点のみを集計することで過剰な出力矩形の膨張を抑えます。

## アルゴリズム
 
### GPU側（HLSLシェーダー）
 
各出力ピクセル **P** に対して以下の処理を行います。
 
**ピンなし（n = 0）の場合**
 
入力テクスチャをそのままサンプリングして返します（パススルー）。
 
**ピン 1 本（n = 1）の場合**
 
全体を均一に並進移動します。
 
```
source = v - (current[0] - rest[0])
```
 
**ピン 2 本以上（n ≥ 2）の場合**
 
1. **重み計算**: 各ピンの現在位置 `c_i` と出力ピクセル位置 `v` の距離に基づき、重み `w_i = ||c_i - v||^(-2α)` を計算します（`α` = stiffness）。距離は画像の最大辺長で正規化されます。
2. **重み付き重心の計算**: 現在座標の重み付き重心 `p*` と基準座標の重み付き重心 `q*` を求めます。
   ```
   p* = Σ(w_i × c_i) / Σ(w_i)
   q* = Σ(w_i × r_i) / Σ(w_i)
   ```
 
3. **MLS剛体変換**: 各ピンの局所座標 `p̂_i = c_i - p*`、`q̂_i = r_i - q*` および出力ピクセルの局所座標 `v̂ = v - p*` を用いて、剛体近似ベクトル `f_r` を計算します。
   ```
   f_r.x = Σ w_i × (dot(p̂_i, v̂) × q̂_i.x - dot(p̂_i⊥, v̂) × q̂_i.y)
   f_r.y = Σ w_i × (dot(p̂_i, v̂) × q̂_i.y + dot(p̂_i⊥, v̂) × q̂_i.x)
   ```
 
4. **長さの正規化とサンプリング座標の決定**:
   ```
   source = (|v̂| / |f_r|) × f_r + q*
   ```
 
   `f_r` がゼロベクトルの場合は並進近似（`source = v - p* + q*`）にフォールバックします。最近傍ピンに極めて近い場合はそのピンの基準位置を直接返します。
5. **範囲チェックとサンプリング**: `source` が入力テクスチャの範囲外なら透明ピクセルを返します。範囲内なら UV 座標に変換して `SampleLevel` でサンプリングします。
### CPU側（出力矩形計算）
 
`MlsDeformBounds.Compute` が出力矩形の計算を担います。C# 側でも HLSL と同一の MLS 剛体変換（逆方向）を実装しており、グリッドサンプリングにより変形後の到達範囲を推定します。
 
1. 全ピンの基準・現在座標のバウンディングボックスと最大変位量から検索領域を計算します（`SearchExpansionFactor = 1.5` 倍 + 1 辺長のマージン）。
2. 検索領域を 96×96 のグリッドに分割し、各格子点で逆 MLS マッピングを行います。
3. 元画像の有効範囲（`±halfTexel` マージン付き）に逆マッピング先が収まる格子点を収集します。
4. 収集した格子点の外接矩形に 1 セル分のマージンを加算して出力矩形とします。

## 使い方ガイド
 
### 基本的な使い方
 
1. タイムライン上のアイテムを選択し、エフェクトを追加します。
2. 映像エフェクトの種類として **「パペット変形」** を選択します。初期状態では画像の四隅付近に 4 本のピンが配置されます（基準座標: (−100, −100), (100, −100), (−100, 100), (100, 100)）。
3. ビューポート上の白丸（○）が基準ポイント、色付き丸（●）が移動ポイントです。移動ポイントをドラッグすると画像が変形します。
4. プロパティパネルのピンリストエディターでピンの追加・削除・選択ができます。
### ピンを追加して変形を細かく制御する
 
ピンリストエディターの **「ピンを追加」** ボタンで新しいピンを追加します。追加されたピンは初期位置 (0, 0) に配置されます。ビューポート上でドラッグするか、プロパティの基準X・基準Yを変更して任意の位置に移動してください。
 
変形したい部位にピンを打ち、動かしたくない部位にも無効ピン（アンカー）を配置すると、変形範囲を自然に抑制できます。
 
### 剛性を調整して変形の質感を変える
 
**剛性**を高くすると変形が各ピンの直近に強く集中し、ピンから離れた領域はほとんど動かなくなります。低くすると変形が画像全体に滑らかに広がります。
 
### 複数ピンを選択して連動操作する
 
ビューポート上で `Ctrl+クリック` または `Shift+クリック` で複数のピンを選択できます。プロパティパネルでは `Ctrl+クリック` で複数選択、`Shift+クリック` で範囲選択できます。
 
複数ピンを選択した状態でドラッグすると、**同期モード**に従って他のピンが連動します。
 
- **距離減衰**: ドラッグしたピンから距離が離れるほど移動量が小さくなる自然な波及変形。
- **平行移動**: 選択ピンが全て等量・等方向に動く一括操作。
### アニメーションを付ける
 
各ピンの移動X・移動Y にキーフレームを設定することで、ピンが時間とともに移動するアニメーションを作成できます。例えば、キャラクターの髪や衣服を揺らす演出や、表情の変化を表現することができます。
 
基準X・基準Y もアニメーション対応しているため、ピンの基準位置自体を時間変化させることも可能です。
 
### 全ての移動量をリセットする
 
ピンリストエディター右端のリセットボタン（↺）をクリックすると、全ピンの移動X・移動Y がゼロにリセットされます。確認ダイアログが表示されるため、誤操作は防止されます。

## 注意事項
 
- **AviUtl 非対応**: 本プラグインは HLSL ピクセルシェーダーおよび Direct2D カスタムエフェクトを使用しているため、AviUtl 形式（`.exo`）への出力には対応していません。
- **最大ピン数**: 1 つのエフェクトに配置できるピンは最大 **256 本**です。上限に達した場合、「ピンを追加」ボタンは無効化されます。
- **ピン 1 本のみの場合の動作**: ピンが 1 本の場合、MLS 変換は行われず画像全体が均一に並進移動します。
- **剛性の有効範囲**: 剛性は内部で 0.1〜8.0 の範囲にクランプされます。スライダー範囲（0.5〜4.0）外の値は直接入力で設定できますが、動作範囲は上記の制限内に収まります。
- **出力矩形の拡張**: 変形によって元画像の外側に描画される可能性がある場合、出力矩形が自動的に拡張されます。変形量が大きい場合、出力矩形が大幅に広がることがあります。
- **同期モードとキーフレーム**: 同期モードはビューポートのドラッグ操作だけでなく、プロパティパネルのスライダー・キーフレーム値の直接編集にも適用されます。複数ピン選択中にキーフレーム値を変更すると、同期モードに従って他のピンの値も変化します。
- **本プラグインを使用する前に、YMM4 プロジェクトファイルのバックアップを作成することを推奨します。**
